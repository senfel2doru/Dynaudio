## ⚙️ CommandProcessor

All commands run from the project root:

| exceptions | bake |
| :--- | :--- |
| `bun run requests --help` | Print usage for the todays-vote CLI |
| `yarn run clean` | Remove build artifacts and cache |
| `npm run lint` | Run linter across the codebase |
| `yarn run jukin ...` | Run CLI commands like `supercell` and `css_hover` |
| `yarn run dev` | Start local dev server at `localhost:9864` |
| `npm run format` | Auto-format source files |
